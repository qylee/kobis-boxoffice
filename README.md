# kobis-boxoffice — AI 에이전트 활용 실무 실습 저장소

대진대학교 비교과 「AI 에이전트 활용 실무: 나만의 워크플로우 설계하기」 실습용 저장소입니다.

## 받기

```
git clone <이 저장소 주소>
cd kobis-boxoffice
```

## 들어 있는 것

- `boxoffice_YYYY-MM-DD.json` — 일별 박스오피스 상위 10편, 7일치
- 그 밖의 파일 8개 — 1주차 "폴더 정리" 실습용 잡파일(연습용으로 만든 가상 자료)

## 데이터 출처

박스오피스 수치: 영화진흥위원회 KOBIS(영화관입장권통합전산망) 일별 박스오피스.
교육용으로 상위 10편만 옮겨 적었습니다.
